### 실험 배경 및 목적

**연구 목표**: PDF 내 테이블을 효과적으로 추출하여 지식 그래프(Knowledge Graph) 구축을 위한 데이터 준비

**연구 배경**:
- 외국에서 개발된 PDF 파서 라이브러리(pdfplumber 등)가 한국 표 형식에 최적화되지 않음
- 한국 표 형식의 특수성: 병합 셀 구조, 계층적 헤더, 한글 텍스트 처리
- 지식 그래프 구축을 위해서는 정확한 표 데이터 추출이 필수적
- 최신 파서 라이브러리로 한국 표 문서를 파싱했을 때 데이터 셀 처리 방식을 확인하여 연구 주제 도출

**연구 질문**:
1. 외국 파서 라이브러리가 한국 표 형식을 어떻게 처리하는가?
2. 데이터 셀 추출 과정에서 어떤 문제가 발생하는가?
3. 추출된 데이터로 지식 그래프를 구축할 수 있는가?
4. 한국 표 형식에 특화된 해결 방안은 무엇인가?

### 실험 방법

**실험 대상**:
- 문서: DMS_[기재정정]사업보고서 (2023.12)_20250321000022.pdf
- 파일 크기: 308페이지
- 표 개수: 544개
- 선정 이유: 문제 점수 75점 (가장 높음), 복잡한 레이아웃 다수 포함

**추출 방법**:
- 도구: pdfplumber (Python 라이브러리)
- 프로세스:
  1. PDF 파일 로드
  2. 각 페이지에서 표 추출
  3. DataFrame으로 변환
  4. 품질 분석 (None 비율, 빈 표, 1행 표 등)
  5. 문제 표 식별 및 주석 추가

**분석 지표**:
- None 비율: 셀 값이 None인 비율 (30% 이상 = 문제)
- 표 크기: 행 x 열
- 빈 표: 데이터가 없는 표
- 1행 표: 헤더만 있고 데이터 행이 없는 표

### 발견 사항

**외국 라이브러리의 한국 표 처리 한계**:

1. **병합 셀 값 복원 실패**
   - 병합 정보는 추출하지만 실제 값은 None
   - 병합된 셀의 원본 값 추출 불가
   - KG 구축 시 엔티티 속성 값 손실

2. **계층적 헤더 구조 인식 부족**
   - 다단계 헤더에서 하위 헤더 값 추출 실패
   - 계층 구조는 인식하지만 값 복원 불가
   - KG의 계층적 관계 표현 어려움

3. **한국어 특수 처리 부재**
   - 한글 폰트 인코딩 이슈
   - 세로/가로 혼합 텍스트 처리 미흡

**공통 패턴**:
- 병합 셀이 많은 표에서 None 비율 높음
- 계층적 헤더에서 하위 헤더 값 손실
- 대형 표에서 누적 손실로 인한 높은 None 비율
