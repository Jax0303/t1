# 표 추출 문제 분석 리포트

## 발견된 문제점

### 1. 빈 표 (Empty Tables)

**발생 빈도**: 모든 테스트 파일에서 발견

**예시**:
- 동진쎄미켐_반기보고서: **45개 빈 표**
- 휴온스글로벌_반기보고서: **22개 빈 표**
- 파멥신_분기보고서: **14개 빈 표**
- 휴온스글로벌_분기보고서: **13개 빈 표**
- 강원특별자치도민프로축구단_반기보고서: **2개 빈 표**

**원인 분석**:
1. **표 구조는 감지했지만 데이터 추출 실패**
   - PDF에서 표 경계는 인식했으나 셀 내용 추출 실패
   - 병합 셀이나 복잡한 레이아웃으로 인한 문제

2. **모든 셀이 None인 경우**
   - 표 구조는 있지만 모든 셀 값이 None
   - 텍스트 인코딩 문제 또는 폰트 문제

3. **빈 DataFrame 반환**
   - 표 감지 후 DataFrame 생성 시도했으나 빈 결과

### 2. 작은 표 (Small Tables)

**발생 빈도**: 일부 파일에서 발견

**예시**:
- 1행 x 3열 표
- 2행 x 1열 표

**원인**:
- 표가 아닌 다른 구조를 표로 잘못 인식
- 헤더만 있고 데이터가 없는 표

### 3. 추출기별 비교

| 추출기 | 빈 표 발생 | 비고 |
|--------|-----------|------|
| **pdfplumber** | 동일한 빈 표 발생 | 표 감지 로직 동일 |
| **pymupdf** | 동일한 빈 표 발생 | 표 감지 로직 동일 |

**인사이트**: 두 추출기가 같은 표를 빈 표로 인식 → PDF 자체의 문제일 가능성

## 문제가 발생하는 파일 유형

### 1. 복잡한 레이아웃 파일
- 다중 페이지 표
- 병합 셀이 많은 표
- 계층적 헤더 구조

### 2. 특정 회사 보고서
- 동진쎄미켐: 빈 표 45개 (가장 많음)
- 휴온스글로벌: 빈 표 13-22개
- 파멥신: 빈 표 14개

## 해결 방안

### 1. 빈 표 필터링
```python
# 빈 표 제거
tables = [t for t in tables if t.get('dataframe') is not None and not t.get('dataframe').empty]
```

### 2. 표 품질 검증
```python
# 최소 크기 검증
min_rows, min_cols = 2, 2
valid_tables = [
    t for t in tables 
    if len(t.get('dataframe', pd.DataFrame())) >= min_rows 
    and len(t.get('dataframe', pd.DataFrame()).columns) >= min_cols
]
```

- 표 품질 점수 계산
- 문제 있는 표 로깅

### 4. 추출기 개선
- 병합 셀 처리 개선
- 복잡한 레이아웃 처리 강화
- 한글 폰트 문제 해결
