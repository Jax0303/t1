# PDF 표 추출과 지식 그래프 구축을 위한 조사 보고서

## 1. 배경과 문제 인식

PDF는 디지털 문서의 표준 형식이지만, 표 형식으로 정형화된 데이터를 표현할 때 여러 문제를 야기한다. 한국 문서에서 사용되는 표는 한글 폰트, 세로 쓰기, 병합 셀 등 특수한 구조를 가지기 때문에 해외에서 개발된 파서 라이브러리로 추출하면 정확성이 떨어질 수 있다. 특히, 법령·공공기관 보고서·재무제표와 같이 한글 기반 문서에서 표 구조가 복잡한 경우가 많다.

이번 연구의 목표는 PDF 내 표 데이터를 정확하게 추출하고 이를 기반으로 지식 그래프를 구축하는 방법을 탐색하는 데 있다. 이를 위해 최근에 공개된 다양한 PDF 파서 라이브러리를 비교하고, 한국어 문서에서 발생하는 문제점을 분석하며, 그 해결을 위한 연구 방향을 제안한다.

## 2. PDF 표 추출 도구 비교

다양한 오픈 소스 파서들이 PDF 파일의 텍스트와 표를 추출하는 데 사용되고 있다. 최근 블로그와 논문에서 보고된 대표 라이브러리들의 특징과 한국어 문서를 대상으로 한 성능은 다음과 같다.

### 2.1 pdfplumber, camelot, tabula‑py

한국어 블로그에서 비교한 결과에 따르면, **pdfplumber**가 세 도구 중 가장 높은 정확도를 보였다[^1]. 이 도구는 표 구조를 인식할 수 있으며 파라미터를 조절해 셀 경계 감도를 높일 수 있다. 다만 병합 셀이나 여러 페이지에 걸친 표는 세 도구 모두 처리하기 어렵다[^1].

**Camelot**은 Lattice(선을 활용)와 Stream(텍스트 간격 활용) 두 가지 모드를 제공한다. 경계선이 뚜렷한 표에는 Lattice, 줄이 없고 공백으로 구분된 표에는 Stream 모드가 적합하며[^2], 추출 실패 시 두 모드를 번갈아 시도하거나 관심 영역을 직접 지정하는 방식으로 정확도를 높일 수 있다[^2]. 그러나 pdfplumber에 비해 표를 놓칠 때가 많다[^1].

**Tabula‑py**는 Java 기반 Tabula를 Python에서 사용할 수 있게 한 것으로 속도는 양호하지만 정확도는 pdfplumber보다 낮고 camelot보다 약간 우수하다[^1].

### 2.2 PyMuPDF(Fitz), PdfPlumber, PyPDF

최근 한국어 Velog 글에서는 RAG 파이프라인 구축을 위해 PyPDF, Fitz(PyMuPDF), PdfPlumber 세 도구를 비교했다. PyPDF는 널리 사용되지만 속도가 느리고 표나 이미지 추출을 지원하지 않아 활용이 제한적이었다[^2].

**Fitz(Python 바인딩을 제공하는 PyMuPDF)**는 로딩과 표 추출 속도가 가장 빨랐고 이미지 추출 기능도 제공한다[^2].

**PdfPlumber**는 표와 이미지 추출을 모두 지원하지만 Fitz보다 처리 속도가 느렸다[^2].

세 도구의 속도 비교표에 따르면 Fitz의 파일 로드와 표 추출 시간은 0.7초와 0.1초 수준으로 PdfPlumber보다 약 10배 빠르며 PyPDF는 10.7초로 가장 느렸다[^2].

### 2.3 최신 비교 연구

2024년 arXiv 논문에서는 PDF 파싱 도구 10종을 비교하였다. 일반 텍스트 추출에서는 PyMuPDF와 pypdfium2가 우수했지만, **Table Transformer(TATR)** 같이 딥러닝 기반 모델이 표 검출에서 뛰어난 성능을 보였다[^3]. 논문은 문서 유형에 따라 최적 도구가 달라지므로 정부 문서나 재무·과학 문서처럼 복잡한 경우 딥러닝 모델을 고려해야 한다고 지적했다. 또한 규칙 기반 파서는 해석이 쉽고 계산 비용이 낮지만 과학·특허 문서에서 한계가 있다고 분석했다[^3].

### 2.4 한국 문서에 특화된 연구

한국전자통신연구원의 연구에서는 문서 이미지의 표 영역에서 단어를 추출하는 방법을 제안하여 100개 한국어 표 이미지에서 **99.16%**의 높은 단어 추출 성공률을 보였다[^4]. 이 연구는 연결요소 분석과 직교선 교차점 보정 등 저수준 이미지 처리 기법을 사용하여 셀을 잘게 분할하고, 투영 프로필과 형태학적 연산을 통해 텍스트 라인을 추출했다. 이러한 기술은 이미지 기반 PDF나 스캔 문서에서 유용하지만 규칙 기반 파서와는 접근 방식이 다르다.

## 3. 한국어 PDF 표 추출 시 고려해야 할 문제

### 병합 셀과 다중 페이지
한국 공공 문서에서는 표가 두 페이지 이상 이어지거나 셀이 크게 병합된 경우가 많다. pdfplumber, Camelot, Tabula 등은 이런 구조에서 정확도가 크게 떨어진다[^1]. 병합 정보를 유지하려면 셀 분할 알고리즘을 수정하거나 수동으로 영역을 지정해야 한다.

### 서식과 폰트 차이
한글 폰트 및 세로 쓰기, 굵은 테두리 등은 선 기반(Lattice) 파서의 성능에 영향을 준다. Stream 모드나 텍스트 간격 기반 방법을 사용하면 일부 문제를 해결할 수 있지만 컬럼 간 간격이 일정하지 않은 표에서는 다시 오류가 발생한다.

### 스캔 또는 이미지 기반 PDF
많은 공공 문서가 스캔본이기 때문에 OCR 과정이 필요하다. OCR 결과의 정확도가 전체 표 해석에 큰 영향을 주며, 한국어 OCR 엔진의 품질이 중요하다.

### 데이터셀이 가진 의미
표에서 추출한 셀은 단순 텍스트일 뿐이며, 지식 그래프 구축을 위해서는 각 열과 행이 어떤 개체나 속성을 나타내는지 해석해야 한다. 이는 Semantic Table Interpretation 영역의 문제로, 셀-개체 연결(CEA), 열 타입 지정(CTA), 열 간 관계 발견(CPA) 등이 필요하다[^5].

## 4. 지식 그래프 구축을 위한 표 해석

표를 지식 그래프로 변환하려면 단순 추출을 넘어 의미 해석이 필요하다. 최근 연구인 **Tab2KG**는 표 열을 온톨로지의 클래스나 속성에 매핑하고 셀 값을 RDF 리터럴로 변환하는 방법을 제안하였다. 웹 표 중 약 3%만이 DBpedia와 일치했기에 도메인별 접근이 필요하며[^6], 도메인별 통계적 특성을 활용한 세만틱 프로파일과 원샷 학습 기법을 통해 새 표를 해석한다[^6]. 

또한 STI(Semantic Table Interpretation) 영역에서 다루는 다섯 가지 핵심 작업—셀-엔티티 매핑(CEA), 열 유형 지정(CTA), 열 쌍 관계(CPA), 표 주제 탐지, 행-인스턴스 매핑—가 지식 그래프 구축의 필수 단계이다[^5].

## 5. 연구 방향 제안

한국어 표 문서에서 PDF 추출과 지식 그래프 구축을 개선하기 위해 다음과 같은 연구 과제를 제안한다.

### 한국어 표 데이터셋 구축
TATR나 Tab2KG 등 최신 모델을 한국 표 양식에 맞게 학습시키려면 표 이미지와 구조 정보, 셀 주석을 포함한 고품질 한국어 데이터셋이 필요하다. 공공 데이터, 법령 문서, 재무 보고서 등을 수집해 병합 셀, 다중 페이지 등 다양한 패턴을 포함하도록 구성한다.

### 규칙 기반 파서 튜닝 및 하이브리드 접근
pdfplumber와 Camelot의 파라미터를 조절해 테두리 인식 민감도를 높이거나 관심 영역을 지정하는 방법을 자동화하는 연구가 필요하다. 예를 들어, 미리 학습된 딥러닝 모델로 표 영역을 검출한 뒤 Camelot에게 해당 영역만 전달하는 방식으로 정확도를 높일 수 있다. PyMuPDF는 속도가 빠르므로 대규모 문서 사전 처리에 적합하다.

### 딥러닝 기반 표 검출 및 셀 분할 모델의 한국어 최적화
Table Transformer(TATR)와 같은 딥러닝 모델은 복잡한 표 구조를 잘 인식한다. 한국어 데이터로 fine-tuning 하거나, 병합 셀과 다중 페이지를 처리할 수 있도록 아키텍처를 개선하는 것이 필요하다. 또한 Scanned PDF를 위한 OCR과 셀 분할 모델을 연결하는 end-to-end 시스템을 연구한다.

### Semantic Table Interpretation의 한국어 지식 그래프 적용
추출된 표를 지식 그래프로 변환하기 위해 Tab2KG의 세만틱 프로파일을 한국 도메인별로 설계하고 원샷 학습 기법을 적용한다. 예를 들어, 금융 보고서 표를 FIBO(Financial Industry Business Ontology)에 매핑하거나, 공공 데이터 표를 정부 온톨로지에 매핑하는 작업을 수행한다.

### 사용자 인터랙션을 통한 오류 보정
완전 자동 파서는 여전히 오류를 내기 때문에, 사용자가 추출 결과를 검토하고 수정할 수 있는 인터페이스를 설계한다. 예를 들어, 병합 셀을 손쉽게 분할하거나 열 타입을 지정하는 도구를 제공하면 지식 그래프 생성 품질을 높일 수 있다.

## 6. 결론

해외에서 개발된 PDF 파서 라이브러리는 한국어 문서에 최적화되어 있지 않으며, 병합 셀·다중 페이지·스캔본 등에서 정확도가 떨어지는 문제가 있다. 비교 결과 pdfplumber가 가장 높은 정확도를 보였지만 속도가 느리고, Fitz(PyMuPDF)는 속도가 빠르지만 표 추출 기능이 제한적이다. Camelot과 Tabula‑py는 특정 조건에서 유용하지만 한국 문서에서는 파라미터 튜닝이 필요하다[^1][^2].

정확한 표 추출과 지식 그래프 구축을 위해서는 한국어 데이터셋 구축과 딥러닝 모델의 현지화, 규칙 기반 파서와 딥러닝 모델의 하이브리드 시스템, 그리고 의미 해석을 위한 STI 기술이 필요하다. 이러한 연구를 통해 한국어 PDF 문서를 기반으로 한 지식 그래프 구축의 자동화를 실현할 수 있을 것으로 기대된다.
