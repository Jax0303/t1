**연구 목표**: PDF 내 테이블을 효과적으로 추출하여 지식 그래프(KG) 구축

## 슬라이드 2: 연구 배경

### 문제 제기

**핵심 문제**: 외국에서 개발된 PDF 파서 라이브러리가 한국 표 형식에 최적화되지 않음

### 한국 표 형식의 특수성

1. **병합 셀 구조**
   - 다단계 병합 셀 (행/열 병합)
   - 계층적 헤더 구조
   - 복잡한 표 레이아웃

2. **한국어 특성**
   - 한글 텍스트 인코딩
   - 세로/가로 혼합 텍스트
   - 특수 문자 처리

3. **공시 문서 특성**
   - 재무제표, 사업보고서 등 구조화된 표
   - 다중 페이지에 걸친 대형 표
   - 표준화된 형식이지만 복잡한 구조

### 연구 필요성

- **지식 그래프 구축의 기초**: 정확한 표 추출이 KG 품질 결정
- **데이터 셀 처리 확인**: 외국 라이브러리가 한국 표를 어떻게 처리하는지 분석 필요
- **연구 주제 도출**: 실험을 통해 발견한 문제점에서 연구 방향 제시

## 슬라이드 4: 실험 설계

### 실험 대상 문서

**DMS_[기재정정]사업보고서 (2023.12)_20250321000022.pdf**

**선정 이유**:
- **문제 점수**: 75점 (가장 높음) ⭐
- **파일 크기**: 308페이지 (대용량)
- **표 개수**: 544개 (충분한 샘플)
- **복잡도**: 병합 셀, 계층적 헤더 다수 포함

```
1. PDF 파일 로드
   ↓

   ↓
3. 데이터 셀 처리 분석
   - None 값 발생 패턴

   ↓
4. 품질 지표 계산
   - None 비율

   - 데이터 손실 지점
   ↓
5. KG 구축 가능성 평가
```

### 분석 지표

- **셀 레벨**: None 비율, 빈 셀 비율
- **표 레벨**: 구조 보존도, 헤더 인식률
- **문서 레벨**: 전체 추출 성공률

## 슬라이드 6: 데이터 셀 처리 분석

### 외국 라이브러리의 한국 표 처리 방식

#### 1. 병합 셀 처리 (가장 큰 문제)

**발견 사항**:
- 병합된 셀을 **None으로 처리**
- 병합 정보(row_span, col_span)는 추출되지만 값은 손실
- **50% 이상 None 비율**의 주요 원인

**예시**:
```
원본: [병합된 헤더 셀]
      ↓
추출: None
```

#### 2. 계층적 헤더 구조

**발견 사항**:
- 다단계 헤더에서 **하위 헤더가 None으로 추출**
- 계층 구조 인식은 하지만 값 복원 실패
- **55.6% None 비율** 발생 (페이지 145, 표 2)

**예시**:
```
원본: [상위 헤더]
      [하위 헤더1] [하위 헤더2]
      ↓
추출: [상위 헤더]
      None        None
```

#### 3. 대형 표 처리

**발견 사항**:
- 33행 x 8열 같은 대형 표에서 **병합 셀 누적 손실**
- 표가 클수록 None 비율 증가
- **53.4% None 비율** (페이지 9, 표 0)

## 슬라이드 8: 지식 그래프 구축 관점에서의 분석

### KG 구축에 필요한 데이터

#### ✅ 잘 추출된 데이터 (90%)

- **단순 표 구조**: 병합 셀 없는 표
- **명확한 헤더**: 단일 레벨 헤더
- **완전한 데이터 셀**: None 값 없는 셀

**KG 변환 가능성**: ✅ 높음
- 엔티티 추출 용이
- 관계 추출 가능
- 속성 값 보존

#### ⚠️ 부분적 추출 (9%)

- **일부 병합 셀**: 일부 값만 손실
- **복잡한 헤더**: 일부 헤더 정보 손실

**KG 변환 가능성**: ⚠️ 제한적
- 엔티티 추출 가능하나 불완전
- 관계 추출 시 정보 손실
- 보간(interpolation) 필요

#### 🔴 심각한 손실 (1%)

- **다수 병합 셀**: 50% 이상 값 손실
- **복잡한 구조**: 헤더 구조 파악 어려움

**KG 변환 가능성**: 🔴 낮음
- 엔티티 추출 어려움
- 관계 추출 불가능
- 대안 방법 필요

## 슬라이드 9: 외국 라이브러리의 한계점

### pdfplumber의 한국 표 처리 한계

#### 1. 병합 셀 값 복원 실패

**문제**:
- 병합 정보는 추출하지만 **실제 값은 None**
- 병합된 셀의 원본 값 추출 불가

**영향**:
- KG 구축 시 엔티티 속성 값 손실
- 관계 추출 시 컨텍스트 부족

#### 2. 계층적 헤더 구조 인식 부족

**문제**:
- 다단계 헤더에서 **하위 헤더 값 추출 실패**
- 계층 구조는 인식하지만 값 복원 불가

**영향**:
- KG의 계층적 관계 표현 어려움
- 엔티티 분류 정보 손실

#### 3. 한국어 특수 처리 부재

**문제**:
- 한글 폰트 인코딩 이슈
- 세로/가로 혼합 텍스트 처리 미흡

**영향**:
- 텍스트 값 추출 실패
- 특수 문자 처리 오류

**문제**: 일부 데이터가 손실되어도 KG 구축 필요

- 불완전 데이터 기반 확률적 KG 구축

**기대 효과**:
- 데이터 손실이 있어도 KG 구축 가능
- 부분적 정보로부터 관계 추론

#### 주제 4: 한국 공시 문서 표 형식 표준화 연구

**문제**: 표 형식이 다양하여 일괄 처리 어려움

- 표 형식 자동 인식 및 적응적 처리

**기대 효과**:
- 형식별 맞춤 처리로 정확도 향상

**Q3. 다른 문서 형식도 분석할 계획인가요?**

- 한국 공시 문서 전체 포괄 목표

**Q4. 실시간 처리 가능한가요?**
- A: 현재는 배치 처리 (15초/문서)
